## 📖 Sobre el proyecto

El **Necronomicón** es una experiencia web inspirada en el legendario libro de los muertos. Abre sus páginas, explora sus secretos y déjate envolver por una atmósfera de horror creada con **sonido, páginas interactivas y animaciones**.

No leas en voz alta. No estás solo.

## 🕯️ La experiencia

- **Páginas interactivas** para recorrer el libro.
- **Sonido** que acompaña la lectura y la oscuridad.
- **Animaciones** que dan vida —o algo parecido— a cada página.
- Una ambientación de terror para adentrarte en el misterio.

## 🩸 Cómo abrirlo

Abre `index.html` en un navegador y comienza a explorar. Para una experiencia más inmersiva, usa auriculares… y no apagues la luz.

## ⚠️ Advertencia

Este libro es una obra de ficción. Cualquier parecido con invocaciones, entidades o susurros detrás de ti es pura coincidencia.

**Pasa la página bajo tu propio riesgo.**
